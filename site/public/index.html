What does my agent actually see?

The tools and saved-login names it can use, then the result of the task. RalX does not return the password. A signed-in browser can still contain private account data. An agent with raw browser debugging access could inspect a filled field before it submits. Read the limits.

Does it work with Clerk or my login page?

RalX handles ordinary single-page and email-then-password forms. Clerk development test accounts have a supported test flow. Unusual widgets, MFA and CAPTCHA may need you to finish in the browser. Production Clerk accounts need their own testing.

Mac, Windows, Linux?

Yes. Local setup supports macOS, Windows and Linux. Setup connects all eight automatically. Anything else that speaks MCP can connect with one snippet.

Is it free?

RalX is free and open source under Apache-2.0. Your computer runs local mode. Self-hosting uses your own Cloudflare and provider accounts, with their own costs. Hosted RalX Cloud is coming soon.

Where do my passwords live?

Local passwords live encrypted in RalX’s store on your computer. In a self-hosted cloud setup, saved secrets live encrypted in your Cloudflare database. The encryption key belongs to that setup. Local programs running as you and a cloud administrator have access that encryption alone does not prevent.
